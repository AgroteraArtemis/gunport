# Thomas Antonio — Original Bright Portfolio

This version recreates the original light, colorful portfolio direction: blue branding, large character hero, handwritten accents, skills row, featured projects, introduction video, About, Education and Contact.

## Add the personal introduction video
Put your real video at:

`assets/thomas-introduction.mp4`

The HTML5 player is already configured for it. Until that file is added, the poster/placeholder remains visible.

## Run locally
Open `index.html` in a browser, or use a simple local server:

`python3 -m http.server 8000`
